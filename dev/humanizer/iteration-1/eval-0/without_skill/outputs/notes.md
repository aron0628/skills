# 수정 내역

## 무엇을 걷어냈는지

| 원문의 문제 | 조치 |
|---|---|
| 이모지 (🚀 ✅) | 삭제 |
| 화살표(→), em dash(—) | 삭제. 표와 소제목으로 대체 |
| 서론 / 본론 1 / 본론 2 / 결론 | 임원 보고 구조로 교체 (요약 → 현황 → 원인 → 방향 → 결정 사항 → 다음 단계) |
| "오늘날 급변하는 비즈니스 환경 속에서", "지금이야말로 과감한 결단이", "진정한 디지털 기업으로 도약" | 삭제. 정보가 없는 문장이라 임원 보고에서 가장 먼저 눈에 걸린다 |
| "단순한 기술 도입이 아니라 생존의 문제", "단편적 개선이 아니라 구조적 전환" | 삭제. "A가 아니라 B" 대구는 AI 문체의 대표 흔적이고, 뺐을 때 잃는 내용도 없다 |
| "결론적으로" | 삭제. 결론을 맨 앞으로 올렸으므로 불필요 |
| "검토될 수 있습니다", "효과적일 수 있습니다", "요청됩니다" | 단정형으로 전환. 이 보고서가 무엇을 주장하는지 드러나야 결재가 된다 |
| "상당한 수준", "크게 개선", "절대적으로 부족", "상당 부분" | 수치 자리로 바꿔 표시 (아래 참조) |
| 볼드 남용 (`**가지고 있습니다**` 등) | 제거 |

## 채워 주셔야 하는 칸

원문에 숫자가 하나도 없어 제가 임의로 만들지 않고 자리만 남겼습니다. 다음 6곳입니다.

1. 데이터 분석 도입 효과 측정 지표
2. 온프레미스 잔존 핵심 시스템 개수
3. 데이터 엔지니어 현재 인원 / 필요 인원
4. 경쟁사 IT 투자 비중 비교 출처
5. IT 투자 예산 계획 기간(연수)
6. 실행 계획 제출 기한, 경영진 회신 기한

이 여섯 개가 들어가면 보고서 성격이 "상황 공유"에서 "결재 요청"으로 바뀝니다. 비워 두면 4장 결정 사항 중 2번은 논의가 진행되지 않습니다.

## 판단이 필요한 두 가지

**문체를 `합니다`체에서 `한다`체로 바꿨습니다.** 사내 임원 보고 양식이 `합니다`체로 고정돼 있으면 되돌리겠습니다. 어미만 바꾸면 되고 내용은 그대로입니다.

**4장 "경영진 결정 필요 사항"은 제가 새로 세운 장입니다.** 원문의 "경영진의 강력한 의지 표명", "각 부서의 적극적인 협조가 요청됩니다", 예산 항목을 한자리에 모아 결정 단위로 다시 쓴 것으로, 없던 내용을 넣지는 않았습니다. 다만 원문이 요청 주체를 흐려 둔 부분을 명시하는 쪽으로 해석했으니, 의도와 다르면 알려 주십시오.
